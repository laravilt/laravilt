# Media

Fields for files and rich content. Their frontend libraries are bundled with `laravilt/forms`, so there is nothing extra to install.

| Component | Description | Built on |
|-----------|-------------|----------|
| [FileUpload](file-upload.md) | Files and images, with an optional Spatie Media Library integration | FilePond |
| [RichEditor](rich-editor.md) | WYSIWYG HTML editor | Tiptap |
| [MarkdownEditor](markdown-editor.md) | Markdown with preview | markdown-it |
| [CodeEditor](code-editor.md) | Syntax-highlighted code | CodeMirror 6 |
