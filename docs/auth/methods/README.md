# Authentication Methods

Each sign-in method is turned on with one panel method, and methods can be combined freely. For example, the login page can offer email and password, social buttons and passkeys at the same time, with two-factor authentication as a second step.

1. [Email & Password](email-password.md): login, registration, password reset, email verification, OTP and magic links
2. [Social Login](social-auth.md): Google, GitHub, Facebook, Twitter, LinkedIn, Discord and Jira
3. [Two-Factor Authentication](two-factor.md): authenticator apps and email codes with recovery codes
4. [Passkeys](passkeys.md): WebAuthn with fingerprint, Face ID or security keys
